
# MULTIGAMES STUDIO

✨ Événements Minecraft exclusifs pour tous les joueurs francophones

**Qui sommes-nous ?**
MultiGames Studio est un studio francophone pour les événements Minecraft : tournois, défis et compétitions de 10 à 60 joueurs, organisés chaque mois.

**Pourquoi nous rejoindre ?**
- Communauté conviviale et modération bienveillante
- Serveurs premium et plugins exclusifs
- Événements uniques et variés
